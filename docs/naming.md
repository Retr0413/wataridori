# Name: Wataridori

`Wataridori` (渡り鳥) means "migratory bird" in Japanese.

A verified image moves from development through staging to production just as a
migratory bird moves safely between destinations:

> Wataridori is a GitOps CD tool for Cloud Run. Your images migrate safely from
> dev to prod.

The name is intentionally distinctive in the Cloud Run and delivery space.
Because it is longer than many CLI names, documentation may show a local
`wtd` shell alias. The distributed binary remains `wataridori`.

Naming and domain availability are operational project decisions and should not
be treated as permanent technical requirements.
