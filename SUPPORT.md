# Support

Wataridori is a pre-release, volunteer-maintained open-source project.

## Questions and bugs

- Read the [README](README.md) and [documentation](docs/).
- Search existing GitHub issues.
- Use the bug-report template for a reproducible defect.
- Use the feature-request template for a scoped proposal.

Include the Wataridori commit or version, operating system, Go version, command,
sanitized manifest shape, and relevant error text.

Do not post access tokens, ADC files, service-account keys, private repository
URLs, production project IDs, or unredacted logs.

## Security

Follow [SECURITY.md](SECURITY.md) for private vulnerability reporting. Security
reports posted as public issues may be removed to protect users.

## Service level

There is no guaranteed response time, compatibility commitment, or production
support SLA before a stable release.
